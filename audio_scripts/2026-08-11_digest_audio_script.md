Short overview
The fresh preserve today is the August 8, 2026 arXiv preprint Sensorimotor features of a reversal learning task bias decision behavior without disrupting individual difference structure. It wins because it goes after a measurement-validity problem that computational psychiatry has been too comfortable ignoring. The paper keeps the task logic fixed and changes only the bodily wrapper: one condition is stationary and arm-reach, the other requires walking between physically separated computers. Accuracy stays basically unchanged, so a lazy read would say nothing important happened. But the metrics people actually like to interpret do move. When the active condition comes first, the later stationary block shows higher stay rate and higher short-lag win-history weights, even though cross-condition correlations remain strong. That is exactly the annoying result worth keeping. It means a task can preserve rank-order individual differences while still shifting the absolute values someone might later threshold, model, or call a biomarker.
That is more useful than another paper claiming a latent variable is stable because the same people are still high or low relative to each other. Stability of ordering is not the same thing as calibration. If a sensorimotor manipulation can add an order-dependent offset without obviously degrading performance, then the field has a translation problem hiding inside apparently respectable reliability. This matters for computational psychiatry tasks moving across desktop, scanner, mobile, and VR settings, and it matters for battery design where one task's bodily demands may contaminate the next task's inferred parameters.

Most relevant paper
Sensorimotor features of a reversal learning task bias decision behavior without disrupting individual difference structure
The paper's useful move is not flashy. It asks whether a standard computational psychiatry task still measures the same thing when the same person performs it under different sensorimotor demands. That sounds mundane, but it is exactly the sort of assumption people skip when they start treating task-derived variables like portable latent traits. Here the task itself stays fixed: same probabilistic reversal structure, same reward contingencies, same two-option choice. What changes is embodiment. In the stationary condition the computers are within arm's reach. In the active condition participants have to walk between separated computers to make each choice.
At the coarse level, the task survives just fine. Accuracy tracks the 70/30 contingency and does not differ meaningfully across conditions. If that were the only metric anyone looked at, the paper would disappear into the drawer. But the finer measures matter more. Stay rate shifts in an order-dependent way, and the same pattern shows up in the lagged logistic-regression weights for prior wins. Participants who do the active condition first show elevated stay rate and stronger short-lag win-history weighting in the later stationary block. Participants who do the stationary block first do not show the same condition effect. So the problem is not generic engagement collapse. It is a structured shift in how recent reward history influences current choice.
The key second result is that the manipulation does not destroy cross-person ordering. Win-stay, lose-stay, and short-lag win-history weights remain reasonably correlated across conditions. That is what makes the paper more dangerous and more worth keeping. A fully broken task would be easier to detect. This result says the task can still look reliable while its absolute scale moves. That is precisely how a field ends up believing it has a stable latent measure when what it really has is a stable rank ordering plus a hidden condition-specific offset.
The caveats are real. This is a healthy university sample, not a patient cohort. The manipulation bundles movement, effort, posture, and probably arousal together, so the causal ingredient is unresolved. And the learned model is a descriptive logistic regression rather than a full process model with reinforcement-learning parameters. But as a preserve, it earns the slot. It sharpens the validity problem instead of decorating it. If a task metric is going to travel across scanner rooms, desks, phones, VR headsets, or mixed clinical batteries, the burden is on the field to show that sensorimotor context is not silently shifting the numbers.
Novelty / framing / baseline impact
For computational psychiatry: reliability of participant ordering is not enough; absolute calibration can still drift with embodiment and task order.
For task-design logic: sensorimotor context and recent sensorimotor history should be treated as possible measurement variables, not just background noise.
For biomarker rhetoric: a metric that survives a condition change in correlation space may still fail in threshold space.
For intervention studies: if adaptive treatment logic or phenotyping pipelines use task-derived decision metrics, cross-platform or cross-battery calibration deserves to become a first-class concern.
For today's clinical lane: the ECT connectome paper looks potentially useful, but accessible text stayed too thin in this environment to outrank a full-text methods warning with cleaner downstream consequences.
One-paragraph takeaway
The August 11 lesson is that a task can stay apparently reliable while still becoming badly calibrated. Today's preserve matters because it shows that changing the bodily wrapper of a reversal-learning task leaves coarse performance intact but can still shift stay-rate and win-history estimates in an order-dependent way. That is exactly the kind of quiet failure mode that could make computational psychiatry look more mature than it is.
