## Short overview

The new preserve is **A personalized map of where, when, and how to stimulate the brain to elicit controlled responses**.

It is worth keeping because it treats response variability as something to map across target, brain state, and paired-region strategy rather than as nuisance noise to average away. The authors train personalized neural-network surrogate brains from HCP resting-state fMRI, validate them against resting and task dynamics, then run exhaustive virtual perturbations over cortical targets, time points, and roughly 80,000 bifocal pairs.

The caveat is not small. This is a preprint, the stimulation is virtual, and the perturbation is a generic BOLD-state bump rather than a device-realistic TMS, DBS, tES, ultrasound, or intracranial-stimulation model. The value is the control logic: if stimulation effects depend lawfully on ongoing whole-brain state and target pairing, then a serious intervention stack should estimate those variables before pretending it has "personalized" a protocol.

## Most relevant paper

**A personalized map of where, when, and how to stimulate the brain to elicit controlled responses**

This is the most relevant paper today because it links three recurring cabbageland questions: where should stimulation enter the network, what brain state should it wait for, and whether a paired node can make the response more reproducible. The dataset is not a clinical intervention cohort. It is 100 healthy HCP participants with long resting-state fMRI scans, plus task-fMRI data for validation. The method is to train one feedforward ANN per participant to predict the next whole-brain activity vector from the recent activity history, then compare perturbed and unperturbed model futures from the same initial state.

The main results are useful because they are operational. Response magnitude increases from unimodal to transmodal cortex. Lower whole-brain baseline activity gates larger and less variable responses. Restricting virtual stimulation to the lowest-energy 5% of time points beats random timing on both size and variability. Bifocal stimulation is more reproducible than the better single site for 73% of cortical pairs, stronger than the stronger single site for 31%, and both stronger and more reproducible for 24%.

Do not inflate it into treatment evidence. The full bioRxiv HTML and PDF were inspected on 2026-10-08, including introduction, validation, main results, methods, limitations, data availability, and code availability. The predictions still need prospective empirical testing with real stimulation and faster measurement. The preserve is the map-making discipline: stimulation variability is partly lawful structure, and a controller should search that structure instead of hiding it under mean effects.

## Novelty / framing / baseline impact

- **For closed-loop neuromodulation:** today's paper makes timing explicit. It predicts that stimulation during low-energy whole-brain states should produce larger and less variable responses than random timing.
- **For network neuroscience:** effective connectivity becomes state-conditioned rather than a fixed matrix. That is the right framing for interventions that act inside ongoing dynamics.
- **For computational control:** the model compares perturbed and unperturbed futures from the same initial state, which is a clean way to isolate single-trial perturbation effects in silico.
- **For multifocal stimulation:** bifocal pairing is treated as a search space for reproducibility, not merely as a way to hit more cortex.
- **For clinical translation:** the HCP fMRI setting is too clean and slow for direct protocol transfer. The next useful test is whether the same logic survives EEG, MEG, sEEG, ECoG, or concurrent TMS-EEG.
- **For baselines:** future "personalized stimulation" papers should be asked whether they compare target-only, state-gated, and paired-target strategies rather than reporting a fragile mean response.
- **For hypnosis and hypnotherapy:** the standing check surfaced recent MEG and decoding work on hypnosis as a brain-state modulation problem, but none displaced today's stimulation-control preserve.
- **For CBT plus interventional psychiatry:** the standing check surfaced CBT plus esketamine, ketamine-CBT, tDCS/CBT, and rTMS/CBT combination items; these remain useful combination-care context, not today's strongest mechanism keep.

## One-paragraph takeaway

October eighth is a reminder that "response variability" is often the paper's most interesting signal. The personalized stimulation-map preprint matters because it does not ask only which node has the biggest average response. It asks which node, in which ongoing state, with which partner node, produces a larger and more reproducible perturbation. The answer is still model-generated and needs real stimulation validation, but the intervention logic is right: state estimation and circuit pairing belong inside the targeting problem, not after it as decorative personalization.
