## Theme

## Short overview

One new preserve today: **Beyond the attractor: closed-loop stimulation design for learning multistable neural dynamics**. PALDI chooses perturbations to learn unknown circuit parameters from noisy, partial spike observations. The useful move is not simply exploring unfamiliar states: it discounts apparently informative responses when uncertainty about the current state could explain them instead.

This is a computational methods preprint, posted October 12, not a clinical demonstration or a paper released today. Its strongest result is transfer from active identification to a separate control task in a simulated spiking circuit. Existing TMS-EEG perturbation and chronic adaptive-DBS notes supply the experimental and deployment reality checks. A connectome-control context note keeps actuator geometry in view. The standing hypnosis/hypnotherapy and CBT-plus-intervention checks were run; no extra canonical note was forced from those discovery results.

## Most relevant paper

**Beyond the attractor: closed-loop stimulation design for learning multistable neural dynamics**

PALDI is the most relevant new preserve because it makes system identification part of the stimulation policy. An attractor can trap passive observations in an uninformative neighborhood; merely seeking uncertain or large responses can instead chase observation noise. PALDI plans finite-horizon inputs using an approximate parameter-information objective, alternating state filtering, blockwise parameter updates, and replanning.

The evaluation is unusually useful for this framing. In a Wilson–Cowan model, median global rollout R² is 0.89 versus a noisy true-model reference of 0.91 across 100 seeds. In a spiking decision network, 20 identification trials produce median held-out R² of 0.90 versus 0.91 for a separately fitted reduced model. But control exposes the remaining gap: change-of-mind success is 0.76 with PALDI versus 0.97 for the fitted reference at the reported fixed budget. Prediction nearly matching a reference is not the same as intervention equivalence.

The translational caveats are substantial: no animals or patients, a known/calibrated observation map, simplified pool-specific actuation, and no demonstrated recording-to-stimulation hardware latency. Preserve the acquisition logic, not a claim that adaptive therapy is solved.

## Novelty / framing / baseline impact

- **Framing:** Separate learning the dynamics from estimating the current state and exploiting a fitted model. A good state decoder need not identify parameters needed for a future intervention.
- **Novelty boundary:** Active system identification, Bayesian experimental design, and receding-horizon planning already exist. The useful contribution is their partially observed neural implementation and the uncertainty-discounted parameter-information surrogate, not invention of closed-loop control.
- **Baselines:** Compare against PRBS/random stimulation, myopic information seeking, finite-horizon uncertainty exploration, and an estimator-matched acquisition ablation. FLEX also changes its parameter estimator here; its performance gap is not a pure acquisition-objective comparison. Interaction budgets are matched, but compute-equivalence is not established.
- **Evaluation:** Require both held-out prediction and a budget-matched intervention task. Report failure tails, observation-map mismatch, state-initialization requirements, and planning latency—not only median fit.
- **Network context:** [Controlling the human connectome with spatially diffuse input signals](https://cabbageland.github.io/cabbageclaw-neuro-daily-web/#/paper_notes/spatially_diffuse_connectome_control_2026.md), an existing note, asks the complementary question of what the actuator can physically reach. Input geometry and information-seeking policy should be tested together rather than treating stimulation as arbitrary independent state injection.

## One-paragraph takeaway

Closed-loop stimulation has three separate jobs: infer the present state, learn how inputs change the dynamics, and deliver a useful intervention under constraints. PALDI strengthens the middle job by asking whether a perturbation distinguishes parameter effects from state uncertainty. Its simulation results justify a real experimental-design baseline, not a therapeutic claim. The next useful test is safe, latency-bounded identification with an imperfect observation model, followed by a held-out intervention—not another attractive phase portrait.
