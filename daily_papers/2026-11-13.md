## Theme

A latent loop is not yet a recurrent digital twin.

## Short overview

One new full-text preserve, with a targeted companion-code audit: spinal population activity traces a low-dimensional loop during stimulation-evoked blood-pressure changes. The representation is interesting; the claim that recurrent circuitry has been captured is much less secure. The published methods set recurrent gain to zero, and the inspected example evaluates a fixed nonlinear feature map on its training trial. Preserve the phase-based representation and the implementation lesson, not the title's implied readiness for closed-loop control.

Two existing notes keep the wider pipeline in view: observation-aware network inference separates measured covariance from latent coupling, while energy-matched DBS supplies a clinical comparator-design constraint. Together these cover computational modeling, network neuroscience, invasive neuroengineering, and clinical/translational neuromodulation without pretending that all three are new discoveries.

## Most relevant paper

**Recurrent latent dynamics in spinal circuits enable a digital twin of autonomic state transitions**

The useful observation is that heterogeneous spinal intermediolateral-neuron responses can be organized into a low-dimensional trajectory associated with the fall and recovery of blood pressure during 40-Hz stimulation in anesthetized male rats. Isomap, phase-based decoding, cross-animal geometric alignment, and a FORCE-style readout make that representation explicit. The paper reports model accuracy of 0.82 versus 0.75 for linear regression and 0.65 for a CNN; these should not be read as prospective, held-out control performance.

The critical implementation check changes the interpretation. In the inspected public `revi_forceregression.py`, `g = 0` removes the recurrent coupling term; `dt = tau = 0.1` additionally reduces the update to the current projected input. Evaluation explicitly uses `tanh(Wz @ X)` on the same trial. This example supports nonlinear reconstruction, not an autonomous recurrent simulator. The Figure 6 narrative, methods, and example code are not interchangeable specifications; a complete numerical reproduction was not performed.

## Novelty / framing / baseline impact

- **Framing:** Separate a latent trajectory, a state-transition model, a stimulation-response model, and a deployed controller. A loop in an embedding does not establish a stable limit cycle, recurrent biological connectivity, or controllability.
- **Baseline impact:** Add stimulus timing/elapsed-time models, matched-capacity random-feature regression, and identical preprocessing/splits across methods. The inspected FORCE example uses the whole trial, whereas the CNN script uses an 80/20 temporal training/validation split before reporting a full-trial score.
- **Transfer:** Fit preprocessing, embedding, alignment, and hyperparameters inside the training partition. Alignment referenced to the measured blood-pressure extremum is calibrated alignment, not target-free transfer to an unseen animal.
- **Clinical/engineering:** Test new stimulation settings and awake longitudinal recordings before calling the representation a digital twin. Then compare closed-loop performance at matched stimulation resources and tolerability; the existing DBS note sharpens this last requirement.

## One-paragraph takeaway

Steal the separation between falling and recovering physiological phases, not the recurrence branding. The next useful experiment asks whether neural population phase predicts held-out responses beyond a stimulus clock, whether an explicitly active recurrent model improves that prediction, and whether its input-response map survives a change in stimulation or subject. Today's common thread is to demand the missing link between a compelling representation and a useful intervention, while keeping measurement assumptions, model execution, and clinical comparison distinct.
