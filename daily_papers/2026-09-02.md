## Most relevant paper

**Temporally constraining source imaging estimates in an underdetermined neural system with eigenmodes of cortical geometry**

This is the most relevant paper today because it does something rare and useful: it tests whether a neat theoretical upgrade actually survives contact with the inverse problem instead of assuming the answer is yes. The starting point is already interesting. Geometric eigenmodes are a compact anatomy-constrained basis for EEG and MEG source imaging. The tempting next move is to say that neural field theory also gives each mode a time-domain story, so source localization should improve if those transfer functions are baked in. This paper checks that directly.

The evaluation is substantial even if it is simulation-heavy. The authors generate **2,038 seizure simulations** with coupled **Epileptor** models, project them through an **88-sensor** EEG forward model, and reconstruct source activity over **20,484 cortical dipoles**. They compare plain geometric eigenmode localization against several temporal variants: an analytical diagonal transfer function derived from neural field theory, empirical transfer matrices estimated from the known source dynamics, hybrid versions that combine analytical within-mode scaling with empirical cross-mode structure, and an oracle time-varying transfer function that serves as an upper bound.

The useful result is blunt. The analytical transfer function mostly does not help. In noise-free conditions it performs substantially worse than the spatial-only baseline across all three main metrics, and even in noisy cases it is inconsistent. The gains appear when the reconstruction includes **cross-eigenmode interactions**. Averaged empirical transfer functions help under noise, simulation-specific empirical and hybrid transfer functions help more, and the oracle case works best of all. That means the missing ingredient is not "add time." It is "add the right interactions between modes."

That matters for cabbageland because it sharpens a general rule that applies far beyond seizure source imaging. A spatial prior is not enough. A temporal prior that assumes independent mode evolution is also not enough. If the real system redistributes activity across modes through recurrent and cross-scale coupling, then intervention logic, source reconstruction, and state estimation all need that coupling structure rather than a single tidy diagonal story.

The main caveat is equally clear. This is a full-text **arXiv HTML** preserve, but it is still mostly a simulation paper. The empirical and oracle wins rely on access to latent source dynamics that experimental scalp EEG does not hand you for free. The paper knows this and treats the real open problem honestly: how to estimate useful cross-modal transfer structure from invasive or multimodal calibration data without sneaking ground truth through the back door.

## Novelty / framing / baseline impact

- **For source imaging:** temporal constraints are not automatically helpful just because they come from respectable theory; the representation of cross-mode coupling is the real bottleneck.
- **For geometry-based modeling:** this pairs tightly with the archive geometry-aware whole-brain note by showing what geometry can and cannot buy on its own.
- **For neuromodulation modeling:** any controller or biomarker model that assumes one latent mode evolves independently is probably throwing away the interaction structure that matters most in noisy real data.
- **For perturbation work:** this sits naturally beside the archive whole-brain TMS-evoked-response note and causal TMS/fMRI mapping note, both of which already imply that anatomy without dynamical specificity is not enough.
- **For methods selection:** simulation-specific hybrid transfer functions appear to be the best non-oracle compromise, which is a better design clue than simply copying the analytical neural-field transfer function.
- **For measurement realism:** the paper's own negative result on the analytical variant is a good standard-setting move; more methods papers should show when the elegant idea fails.
- **For standing-interest lanes:** today's CBT-plus-interventional and hypnosis checks produced citation material and durability follow-up, not a stronger mechanistic or interventional preserve.

## One-paragraph takeaway

The useful September second lesson is that a good spatial prior is not a time machine. Today's preserve shows that adding analytically derived temporal structure to geometry-based source imaging does not reliably help unless the method also captures how modes interact. That is a valuable correction for a lot of current neuroengineering and intervention-modeling rhetoric. Better anatomy helps. Better temporal structure helps. But the real payoff appears when the model stops pretending the brain's relevant modes evolve independently.
